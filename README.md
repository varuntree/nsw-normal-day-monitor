# NSW Normal Day Monitor

Live page for a UNSW DATA5925 (Term 3 2026) student project: each day it compares NSW electricity demand and train tap-ons with a forecast of a normal day and raises an alarm when the pattern shifts.

Group 5: Sihan Wang, Yihan Zhang, Varun Prasad Gopisetti. Supervisor: Bao Khue Tran.

Data: AEMO (NSW demand), Transport for NSW (Opal). Student project, not operational advice.
